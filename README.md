# ARYA
This repository contains a CFD solver that solves the canonical lid-driven cavity flow (`sliding lid') problem on a uniform mesh using a finite-volume method with a first order upwind advection scheme. The sliding lid is shown in Figure 1. Momentum is diffused from the slip wall and eventually forms a large vortex that settles in the domain, and as the Reynolds number increases, secondary vortices form at the bottom corners.
